Build your own native client for iOS, Android, desktop or the web with the {{ brand }} API. Third-party apps — such as Hotdroid for Android and Macnews for macOS — can extend the core reading experience with features like offline reading, custom filters and notifications.

The API is public, read-only and requires no authentication. Paginate any GET endpoint by appending the ?p=number query parameter (10 entries per page).

GET Endpoints

  • /api/hot — hottest articles ordered by highest similarity score, one per domain
  • /api/cold — coldest articles ordered by lowest similarity score, one per domain
  • /api/new — newest articles ordered by publication time, one per domain
  • /api/{site} — articles from a specific publication ordered by highest similarity score

Response Envelope

  • page — current page number (integer, starts at 1)
  • pages — total number of available pages (integer)
  • view — active view name (hottest, coldest, newest or site)
  • site — publication identifier (present on /api/{site} responses)
  • entries — list of serialized article objects for the current page

Article Object

  • id — unique MD5 identifier of the canonical article URL
  • url — canonical URL of the article
  • title — article headline
  • domain — publisher hostname without www. (e.g. theverge.com)
  • site — publication slug used in routes (e.g. theverge)
  • pub — publication UTC timestamp in seconds (float)
  • age — human-readable relative age (e.g. 2h, 1d)
  • author — article author name when provided by the feed
  • description — full plain-text description extracted from the RSS entry
  • summary — description truncated to 480 characters
  • score — raw cross-publication similarity score (float)
  • degrees — rounded temperature score (round(score * 1000))
